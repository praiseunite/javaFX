A

ACID
Atomicity, Consistency, Isolation, Durability — the four guarantees a transaction gives. — Session 8
API
Ready-made classes and methods you can use. — Session 1
Atomic
An operation that happens completely or not at all, with no half-steps. count++ is not atomic. — Session 5
AtomicInteger, LongAdder
Classes that do an increment as one indivisible step, with no lock written by hand. — Session 5
Atomicity
The property that a half-finished transaction can never be observed. — Session 8
Auto-commit
The default mode where every statement is its own transaction. Turned off to begin one. — Session 8

B

Base bundle
Messages.properties, with no locale in its name. The file of last resort, and the one that must hold every key. — Session 9
Batch update
Queuing many statements with addBatch() and sending them in one call with executeBatch(). — Session 8
BatchUpdateException
The failure a batch throws; getUpdateCounts() reports which statements had already run. — Session 8
Binary search
Finding a value in sorted data by repeatedly halving the search area. — Session 1
Bounded type
<T extends X>: T must be X or a subtype of X. — Session 2
Buffer, flush
A block of memory that collects data to reduce disk trips / forcing buffered data out to the disk. — Session 3
Byte, byte stream
A value 0–255 / a stream that moves raw bytes (InputStream/OutputStream). — Session 3
ByteBuffer
A fixed-size block of bytes with a position, a limit and a capacity — and flip() to switch it from writing to reading. — Session 9

C

CachedRowSet
A disconnected RowSet: rows are read into memory and stay usable after the connection closes. — Session 8
caching_sha2_password
MySQL 8's default authentication plugin. Stronger than the old one, and the reason for the public-key message. — Guide
CallableStatement
The JDBC statement for calling stored routines: { ? = call name(?) }. — Session 8
Channel
A java.nio connection that reads and writes bytes, usually into or out of a ByteBuffer. — Session 9
Character stream, encoding, UTF-8
A stream of text characters (Reader/Writer) / the rule that turns characters into bytes / the standard encoding (1–4 bytes per character). — Session 3
Charset
The mapping between characters and bytes. Name it explicitly; never rely on the machine's default. — Session 9
Checked exception, try-with-resources
An error you must catch or declare (IOException) / try (…), which closes resources automatically. — Session 3
Circular wait
The condition a deadlock needs: each thread holds what the next one is waiting for. — Session 6
Classpath
The list of places the JVM looks for classes and jars. Your driver must be on it to run, and on it again to compile. — Guide
Collection, element
A container object / one item inside it. — Session 1
commit()
Makes everything since the last commit permanent. — Session 8
Comparable / Comparator
A class's own natural order / a separate, swappable sorting rule. — Session 1
Compile time / run time
When code is checked and translated / when it actually runs. — Session 2
Compile-time vs run-time failure
A refusal from javac before anything runs, versus a fault that waits for the right input at 3 a.m. — Session 6
CompletableFuture
A promise of a result that arrives later, with steps chained onto it. — Session 5
Concurrency, scheduler
Several things in progress at once / the OS part that decides which thread runs. — Session 4
ConcurrentHashMap, BlockingQueue, CopyOnWriteArrayList
Thread-safe collections that do the locking, waiting and waking for you. — Session 5
Connection
An open session with the database. A resource: close it when done. — Session 7
Connector/J
MySQL's official JDBC driver. Driver class com.mysql.cj.jdbc.Driver. — Guide
Console
The class for talking to a real terminal, including hidden password input. — Session 3
CREATE ALIAS
H2’s way of exposing a Java method as a database routine — its substitute for PL/SQL. — Session 8
Critical section
The lines of code that touch shared data and must run for one thread at a time. — Session 5
CSV
Comma-separated values: a simple text format for tables. — Session 3

D

Daemon thread / user thread
A background thread that doesn't keep the JVM alive / one that does. — Session 4
DAO
Data Access Object — the older, narrower idea: an object that owns the SQL for one table. A repository usually contains one. — Session 7 · Session 9
DatabaseMetaData
A description of the database itself: tables, columns, keys, features. — Session 7
Deadlock, lock ordering
Threads frozen in a circular wait / the one agreed sequence that makes it impossible. — Session 5
Design pattern
A named, reusable solution to a recurring design problem — and, more usefully, a name for a change that has already been paid for. — Session 9
Dirty read
Reading a row another transaction changed but has not committed. — Session 8
Driver
The vendor's jar that implements the java.sql interfaces for one database. — Session 7
Driver (JDBC driver)
The vendor's jar that translates java.sql.* calls into a specific database's language. — Guide
DriverManager
The class that reads a JDBC URL and hands back a Connection from the matching driver. — Session 7

E

Embedded database
A database engine that runs inside your program, as a library, with no separate server process. H2 is one. — Session 7 · Guide
EOF
End Of File. — Session 3
ExecutorService
An object that runs submitted tasks on threads for you (more in Session 5). — Session 4

F

Facade
A single simple front over a complicated subsystem — which is what Db is for JDBC. — Session 9
Factory
A class whose job is to decide which implementation you get, so that nothing else has to know. — Session 9
Failure report
The message a check or a compiler prints: the type, the method, the line, and what it expected. — Session 6
Fallback chain / candidate locales
The ordered list of bundles tried for a locale: fr_CA → fr → the root file. — Session 9
FIFO, LIFO, Deque
First-in-first-out (queue) / last-in-first-out (stack) / double-ended queue. — Session 1
File lock
A marker H2 places while a file database is open, preventing a second process from writing it. The cause of "may be already in use". — Guide
Files
The class of static operations on Paths: read, write, copy, move, walk, delete. — Session 9
FileSystem
An abstraction over a file system — the disk, or the contents of a zip file, addressed the same way. — Session 9
Functional interface
An interface with one abstract method, which is therefore what a lambda can implement. — Session 9

G

Gang of Four (GoF)
The four authors of Design Patterns (1994), and by extension its twenty-two patterns, grouped as creational, structural and behavioural. — Session 9
Generated key
The id a database assigns to an inserted row, read with getGeneratedKeys(). — Session 7
Generic class, generic interface, generic method
A class / interface / method that declares its own type parameter(s). — Session 2
Generics
Classes, interfaces and methods that take types as parameters. — Session 2
Generics <T>, diamond <>
The type of element a collection holds; Java fills in the right-hand side for you. — Session 1
Glob / PathMatcher
A shell-style pattern (**/*.txt) and the object that tests a Path against it. — Session 9
GRANT
MySQL's way of giving a user rights, always scoped to particular objects. GRANT ALL ON registry.* is scoped to one database. — Guide
Guarded block, spurious wake-up
A while-loop around wait() / a wake-up that happens with no signal, which is why the loop is required. — Session 5

H

Hash code, bucket
The number an object turns itself into / the slot a HashSet or HashMap puts it in. — Session 1
Heap
The internal shape of a PriorityQueue: the smallest is always on top. — Session 1

I

In-memory database
A database that exists only in RAM and vanishes when the last connection closes. Fast, and deliberately temporary. — Guide
Index
A position number, starting at 0. — Session 1
Instantiate
Create an object from a class: new Box<>(). — Session 2
Interface vs class (implementation)
The rules ("job advert") vs the object that does the work. — Session 1
Internationalization (i18n)
Writing the program so that no user-visible text or format is baked into the code. — Session 9
Intrinsic lock / monitor
The built-in lock every Java object carries; what synchronized uses. — Session 5
Isolate
To narrow a fault down to one method, then one line, so that the fix is obvious. — Session 6
Isolation level
How much of each other’s unfinished work concurrent transactions may see. — Session 8
Iterator
A cursor that walks through a collection (hasNext, next, remove). — Session 1

J

java.io
The original stream API: one-directional, positionless, universal. — Session 9
java.nio
The channel-and-buffer API: two-directional, keeps a position, and can move data without copying it through user code. — Session 9
java.nio.file / NIO.2
The modern file API: Path, Files, FileSystem and PathMatcher. — Session 9
JDBC
Java Database Connectivity: the JDK's API for talking to a relational database. — Session 7
JDBC URL
The string that names a database and tells DriverManager which driver to use. The jdbc: prefix, then a vendor protocol. — Guide
join, sleep, interrupt
Wait for another thread / pause this one / politely ask a thread to stop. — Session 4

K

Key, value, entry
The lookup part / the stored part / one key=value pair of a Map. — Session 1

L

Lambda x -> … / method reference Class::method
A short inline function / a shortcut for a lambda that just calls one method. — Session 1
Locale
A language, optionally with a region and a variant — fr, fr_CA. It is data your program carries, not a global setting. — Session 9
Localization (l10n)
Supplying the text and formats for one particular language and region. — Session 9
Lock ordering
Agreeing a single sequence for taking several locks, and following it in every thread. — Session 6
Lost update
An increment that one thread overwrites before another has finished with it. — Session 5

M

Marker interface, serialVersionUID, transient
An interface with no methods (Serializable) / a class's version number / "don't save this field". — Session 3
MessageFormat
The class that fills {0} holes in a pattern — and treats a single quote as an escape character. — Session 9
Model–View–Controller (MVC)
A three-way split: the model decides the rules, the view decides the presentation, the controller decides the wiring. — Session 9
Multithreading
One program doing several jobs at the same time, each on its own thread. — Session 5
Mutual exclusion / visibility
Only one thread inside at a time / a lock's guarantee that changes are seen by the next thread. — Session 5

N

Non-repeatable read
Reading the same row twice inside one transaction and getting two answers. — Session 8

O

Observer
A subject that holds a list of listeners and tells them when something happens, without knowing what any of them do. — Session 9
Open/Closed principle
Open to extension, closed to modification: add a class instead of editing the ones that work. — Session 9
Optional
A container that either holds a value or explicitly holds nothing — a return type that admits "not found". — Session 9

P

Package / import
A folder of related classes / the line that lets you use a class from another package. — Session 1
Parameterized query
A query whose values are bound through ? — the defence against injection. — Session 7
Path
A name for a file or directory, possibly not existing — deliberately not the same thing as an open file. — Session 9
Path, relative path, working directory
A file's address / an address measured from the current folder / the current folder (the project folder in IntelliJ). — Session 3
PECS
Producer Extends, Consumer Super: the rule for choosing a wildcard. — Session 2
Phantom read
Running the same query twice and getting a different set of rows. — Session 8
Pinning
When a virtual thread can't release its carrier while waiting (mostly fixed since JDK 24). — Session 4
Platform thread / virtual thread / carrier thread
A wrapper around an OS thread / a cheap thread managed by Java / the platform thread a virtual thread runs on. — Session 4
Port
The number a network service listens on. MySQL's default is 3306; H2's server and console use 9092 and 8082. — Guide
PreparedStatement
A statement with ? placeholders; values are bound separately and can never become SQL. — Session 7
Priority
A 1–10 hint to the scheduler, never a guarantee. — Session 4

R

Race condition
A bug where the timing of threads corrupts shared data. — Session 5
Raw type
A generic type used without <…>, like List. Unsafe; only for old code. — Session 2
Record
A class whose entire content is its data: the constructor, accessors, equals, hashCode and toString are generated. — Session 9
Regression
Something that used to work and no longer does, because of a change made somewhere else. — Session 6
Repository
An object that presents your data as a domain collection and hides where it comes from. Here: StudentRepository. — Session 9
Reproduce
To make a fault happen on demand. Without this you cannot tell a fix from a coincidence. — Session 6
Resource leak
A file handle, connection or thread that is never released. Harmless once, fatal after a few thousand times. — Session 6
ResourceBundle
The Java object that looks up a key in the right .properties file for a locale, walking up the parent chain when a key is absent. — Session 9
ResultSet
A cursor over the rows a query returned. Starts before row one; next() advances it. — Session 7
ResultSetMetaData
A description of one query's result: column count, names and types. — Session 7
rollback()
Undoes everything since the last commit. Does nothing when auto-commit is on. — Session 8
RowSet
A ResultSet that is also a JavaBean: configurable, fillable, and passable between layers. — Session 8
RowSetProvider / RowSetFactory
The two-step way to obtain a RowSet, so the provider can be swapped without changing your code. — Session 8
Runnable
An interface with one method, run(): a job a thread can do. — Session 4

S

Savepoint
A bookmark inside a transaction; rollback(point) rewinds to it, keeping earlier work. — Session 8
Scrollable ResultSet
A cursor you can move in any direction, instead of only forwards. — Session 8
Seam
A place in the code where behaviour can be swapped without editing the code around it. An interface is the usual way to make one. — Session 9
Self-check
A program that measures your own work and prints a pass/fail count, so correctness is a number rather than an opinion. — Session 6
Serialization / deserialization
Turning an object into bytes / rebuilding a copy from them. — Session 3
Sharding key
A value naming which shard a connection belongs to, when one database spans several servers. New in JDBC 4.3. — Session 8
Silent failure
A fault that throws nothing and exits cleanly — an empty file, a duplicated student, a serialised job. The hardest kind to find. — Session 6
Singleton
A class with exactly one instance, reachable from everywhere — useful for configuration, dangerous everywhere else. — Session 9
SQL dialect
The specific spelling of SQL that a database accepts. Standard SQL is the common core; the edges differ. — Guide
SQL injection
An attack where input concatenated into SQL changes the query's meaning. — Session 7
start() / run()
Begin a new thread that runs the job / the job itself. — Session 4
Statement
A channel for fixed SQL with no input values. — Session 7
Static method
A method you call on the class name, such as Arrays.sort(a), without new. — Session 1
Stored procedure
A routine that lives in the database and is called with a CallableStatement. — Session 8
Strategy
An interchangeable algorithm behind one interface, chosen at the call site. Here: FeePolicy. — Session 9
Stream, input stream, output stream
An ordered flow of data into / out of a program. — Session 3
Switch expression
A switch that produces a value, with arrow cases and no fall-through. — Session 9
Symptom vs cause
What you can see (the wrong total) versus why it happens (a lost update). Fixing the symptom is the most common beginner mistake. — Session 6

T

Text block
A multi-line string literal written with """, so the text in the source is the text you get. — Session 9
Thread dump, ThreadMXBean
A snapshot of every thread and what it is doing / the JVM API that can name the threads in a deadlock. — Session 5
Thread pool, ExecutorService, Future
A managed set of reused threads / the manager you submit tasks to / the receipt you call get() on for a result. — Session 5
Thread states
NEW, RUNNABLE, BLOCKED, WAITING, TIMED_WAITING, TERMINATED. — Session 4
Thread, process, main thread
A path of execution / a running program / the thread that runs main. — Session 4
Transaction
A group of statements the database treats as one unit: all of it, or none of it. — Session 8
Two-tier / three-tier
SQL written inline (two-tier) versus SQL behind a DAO (three-tier). — Session 7
Type erasure
The compiler removes type arguments after checking them; at run time T is Object (or its bound). — Session 2 · Session 6
Type inference
The compiler working out a type you didn't write. — Session 2
Type parameter / type argument
The placeholder (T in Box<T>) / the real type that fills it (String in Box<String>). — Session 2
Type witness
Naming the type yourself on a generic method call: List.<Integer>of(). — Session 2

U

Updatable ResultSet
A cursor that can edit the row it is on with updateRow(), insertRow() or deleteRow(). — Session 8
utf8mb4
The MySQL character set that stores the full range of Unicode, including emoji. The right default for text. — Guide

V

Virtual thread, carrier thread, pinning
A cheap thread managed by Java / the platform thread it runs on / when a virtual thread cannot release its carrier while waiting. — Session 5

W

Wildcard ?
"Some unknown type." Upper-bounded ? extends X, lower-bounded ? super X, unbounded ?. — Session 2
Wrapper class, autoboxing
Integer for int and so on; Java converts automatically. — Session 1
Wrapping (Decorator)
Building a stream by putting one inside another, each adding a skill. — Session 3
